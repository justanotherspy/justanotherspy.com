01
Brand Brief

justanotherspy.com is a personal site and project hub for a security and infrastructure engineer based in Cape Town. A professional presence, not a portfolio in the traditional sense. The name carries the personality so the design does not have to.

The site hosts a brief bio, a small number of projects (beginning with garlic and the site itself), and occasional writing on security, AI, and infrastructure. Built for engineers and technical hiring managers.

Core character: dry, considered, unhurried. Never ironic. Never explaining itself.

06b
Code Blocks

Syntax highlighting is handled by Shiki, which ships with Astro. A custom Shiki theme JSON (derived from this spec) is configured in astro.config.mjs to output pre-highlighted HTML at build time -- no client-side JS. Two themes are registered: one for light, one for dark. CSS media query or a data attribute on <html> switches between them.

Code blocks always show a header bar with the language label and an optional filename. Token colours introduce a small satellite palette used exclusively inside code blocks -- they do not appear elsewhere in the UI.

Token colour roles (code-only): keywords / flags use terracotta (already in palette). Strings use warm sage. Numbers and booleans use amber. Object keys and identifiers use slate blue. Comments are muted and italic. All other text uses near-black / warm white.

Astro config: shikiConfig: { themes: { light: './src/themes/jas-light.json', dark: './src/themes/jas-dark.json' } }

Supported languages at launch: bash, json. Python to be added when needed -- same token colour spec applies.

08
Voice & Tone

Dry without being cold. Brief without being terse. The site does not sell anything.

Write like this

"A CLI tool for tracking time spent in Claude Code sessions. Nothing more."

"Notes from someone who spends too much time thinking about infrastructure."

"Security engineer. Cape Town."

Not like this

"I'm a passionate full-stack engineer who loves building things that matter!"

"Welcome to my corner of the internet where I share my journey."

"Check out my latest projects below 👇"

09
Usage Guidelines

Hard constraints. Not preferences.

NO
Gradients. The palette is flat.
NO
Drop shadows or blur effects, except the defined hover shadow on Button C and project cards. Those are the only permitted shadow moments.
NO
Additional accent colours. Terracotta is the only hue.
NO
Terminal or hacker aesthetics. Monospace is for metadata and labels only.
NO
Wordmark in bold, italic, or all-caps. The small mark j.a.s. uses italic deliberately and is the only exception.
NO
Emojis, exclamation marks, or copy that sells anything.
NO
Purposeless animation. Permitted: hover lift on Button C and cards, footer link colour transition, theme toggle fade. Nothing else.
NO
Image borders or box shadows on post images. Rounded corners only.
NO
Button C on home, notes list, or individual post pages. Project pages only, max once.
